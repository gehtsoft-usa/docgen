tag example in Document Source Format

Brief

An example.

Parameters
title

The title of the object
transform

A flag indicating whether the content contains BB-codes
show

A flag indicating if the example must be fully displayed by default (for output templates that supports collapsing of the examples)
if

A name of the definition to be set in the doc project file in order to include the object into the documentation. The value is optional. If no value is set, the object will be always included
gray

A flag indicating whether the example must be displayed on gray background
tabs

A flag indicating whether the example tag contains the text in its body or has one or more tab.

NOTE: If tabs are enabled all the content must be in the tabs!
highlight

The name of the programming language to do the syntax highlighting (if supported by the output template)

Starting from version 0.1.30 the value may also be a diagram. In this case the diagram in mermaid format will be displayed instead of a source code.

Please note that mermaid does not handle correctly the elements which aren't displayed initially, so use highlight=diagram only together with show=yes or show=always properties.

Details

The element may contain the following elements: tab, example, headline, list, table
