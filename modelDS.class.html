tag class in Document Source Format

Brief

The class specification

Parameters
parent

The name of the parent class. Note: it is not a key to a parent class in the documentation, just an arbitrary text
import

The flag indicating that the class must also display members of another classes (e.g. to use it include parent's class members)
name

The name of the object
sig

A signature of the class
prefix

A prefix for the class name
key

The unique key of the article (must be unique among articles, groups and classes)
brief

A brief (one-two sentence) summary of the object
type

A type of the class. The types interpretation depends on the template used.
membersToContent

The flag indicating whether members of the class needs to be exposed in the content tree
ingroup

The key of the group to which the object belongs to. All objects except the index group must belong to some group
if

A name of the definition to be set in the doc project file in order to include the object into the documentation. The value is optional. If no value is set, the object will be always included
sort

The flag indicating whether the members needs to be sorted by the name ("yes" by default)
declname

The name of the class to be used in declarations (the same as the class name by default)
transform

A flag indicating whether the content contains BB-codes
writeSignatures

yes, no, def

The flag indicating whether the signatures (aka name plus parameters) of the methods will be added to the list of the methods and constructors in the class.

The option is useful for classes with lot of overloads.

Details

The element may contain the following elements: declaration, example, headline, list, member, param, see, table
