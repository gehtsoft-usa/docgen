Function methodkey

Brief

Generates a 3-character unique value for the specified string

Declaration
XPATH
methodkey (text : string) : string 

Details

The method is typically used to generate an unique suffix method key depending on the method signature.

The returned value is a CRC32 of the text in UTF-8 encoding in base62 (upper and lower case plus numbers) encoding.

The function introduced in docgen 0.1.17.
