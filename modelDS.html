tags Document Source Format

Brief

The section describes format of the documentation source tags.

Details

At the top level of the documentation file only following elements may be used article, class, group

The diagram below shows the hierarchical structure of the model.

Tags

article

The article

class

The class specification

col

A table column

declaration

A specification of a method for a language specific declaration

example

An example.

exception

A description of the exception thrown by the method

group

A group of articles, classes and other groups

headline

A header in the description

list

A list

list-item

An element of a list

member

A member of a class

note

A note (highlighted piece of text)

param

A parameter of a member of a class or of a generic class

return

A value returned from a class

row

A table row

see

A see-also reference to another topic

tab

A tab in the example item.

table

A table

back
