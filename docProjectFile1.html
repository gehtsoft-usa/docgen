tags project.xml file

Brief

The section describes XML file defining the documentation project

Details

The project file is an XML file that must use the namespace http://www.gehtsoft.com/docgen/project The root tag of the project file must be help-project.

Tags

common

The tag consists of the definitions that are common for all templates and for the parser

define

The tag defines a constant.

file

The tag defines an input file

folder

The tag defines a source folder.

help-project

The root element of the project document

output

The tags defines the output template to be used

source

The tag consists of source files and folders
