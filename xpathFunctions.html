functions XPath extensions

Brief

The list XPATH functions that may be used in output templates

Details

Docgen XPATH extension functions are provided to overcome limits of XSLT 1.0 specification, introduce variables concepts and to overcome a natural XSLT limit that does not allow to create multiple files from one model using one XSLT.

While some of these extensions (such as variables) may contradict to XSLT concept, they greatly reduces the time to develop complex templates.

All extension functions are located in urn:gehtsoft-exslt namespace. Refer the namespace in your XSLT file in order to be able to use this functions.

<xsl:stylesheet
    version="1.0"
    xmlns:ext="urn:gehtsoft-exslt"
    xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
    <xsl:output method="html" />
    <xsl:namespace-alias stylesheet-prefix="ext" result-prefix="#default"/>
    <xsl:template match="/" >
        <xsl:value-of select="ext:let('root', /) "/>
        ...
    </xsl:template>
</xsl:stylesheet>

ltrim

match

methodkey

parse

parsebbcode

removehtml

replace

replaceentity
