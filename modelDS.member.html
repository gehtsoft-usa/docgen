tag member in Document Source Format

Brief

A member of a class

Parameters
name

The name of the object
sig

A platform-specific signature of the member (e.g. for .NET type)
visibility

Visibility of the member (e.g. public, protected)
scope

The scope of the member (static or instance)
brief

A brief (one-two sentence) summary of the object
type

The type of the member (e.g. field, property, method)
key

The unique key of the article (must be unique among articles, groups and classes)
divisor

A divisor between the class name and method name to be used (a dot (.) by default)
if

A name of the definition to be set in the doc project file in order to include the object into the documentation. The value is optional. If no value is set, the object will be always included
excludeFromList

The flag indicating whether the member must be excluded from list of members in the class
transform

A flag indicating whether the content contains BB-codes

Details

The element may contain the following elements: declaration, example, exception, headline, list, param, return, see, table
