tag article in Document Source Format

Brief

The article

Parameters
title

The title of the object
ingroup

The key of the group to which the object belongs to. All objects except the index group must belong to some group
brief

A brief (one-two sentence) summary of the object
key

The unique key of the article (must be unique among articles, groups and classes)
if

A name of the definition to be set in the doc project file in order to include the object into the documentation. The value is optional. If no value is set, the object will be always included
transform

A flag indicating whether the content contains BB-codes
aliasId

The alias of article for HtmlHelp topic list
excludeFromList

The flag indicating whether the article should not be displayed in the list of the articles in the group and content tree

Details

The element may contain the following elements: example, headline, list, see, table
