Formatting: Using Markdown-style formatting

Brief

The article describes markdown-style formatting

Details

The docgen also partially supports using of MarkDown-style formatting.

The enable markdown style formatting add define with the name simplified-text-syntax to common section of the project file.

Text formatting

Code Samples

To insert a code sample you can put it between triple back quotes ```. The first one should define the language name for syntax highlighting (use text to no formatting)

   ```csharp
    if (a > b)
        Console.WriteLine("A is bigger");
   ```

Will be displayed as:

    if (a > b)
        Console.WriteLine("A is bigger");

You can make the example collapsible by adding a plus (+) sign to make it expanded or a (-) sign to make it collapsed.

   ```+csharp
    if (a > b)
        Console.WriteLine("A is bigger");
   ```

Headers

To mark a line as a header, start it with # character. The number of characters defines the level of the header.

# Header Level 1
## Header Level 2
### Header Level 3
#### Header Level 4

Header Level 1

Header Level 2

Header Level 3

Simple lists

To make a simple list use *, - as the first character of the line. The list lines follows the same rule a paragraph - the next item starts after the empty line or with the next line starts with list character.

    * Item 1
    - Item 2
    * Item 3
      is a multi-line line
    * Item 4

  • Item 1

  • Item 2

  • Item 3 is a multi-line line

  • Item 4

Numbered Lists

The numbered lists similar to bullet list, the only difference is that the symbol 0 should be used in first item. The rest items may have either 0, *, or -.

    0 Item 1
    0 Item 2
    * And this is numbered list too
    * Item 4

  1. Item 1

  2. Item 2

  3. And this is numbered list too

  4. Item 4

Tables

To format the table use | character a column delimiter. Markdown based tables cannot have values longer than 1 line. | character must be the first character in the line.

Example: |cell1|cell2|cell3|

cell1

cell2

cell3

To make a row header put !, after the first |

Example: |!,cell1|cell2|cell3|

cell1

cell2

cell3

To make the table 100% width put > character at end of the first line of the table

Example: |cell1|cell2|cell3| >

cell1

cell2

cell3

To define the width of the column put size in percents after | character followed by ,.

Example: |50%,cell1|25%,cell2|25%,cell3| >

You can specify both, the width and the header flag

Example: |!50%,cell1|25%,cell2|25%,cell3| >

To add more lines put them right after the first line. You can also use formatting inside the table
