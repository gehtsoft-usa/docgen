Source code principles

Brief

The article describes the common principles of the source organization

Details

The documentation source format is a plain text format with documentation-specific tags.

The documentation markup always starts with @ character at the first character of the code (after any number of the whitespace characters).

A tag is a section of text between the opening tag and special keyword @end. Each tag may contain values, plain text and sometimes other tags.

An attribute is always one line construction and consists of the name of the value, and = character followed by the value.

The text which does not starts with @ character is considered plain text. Following rules applies to the plain text:

1) All leading whitespace characters are trimmed. If you need to keep leading whitespace characters put ! character in the beginning of the line.

2) All consecutive lines are concatenated in one paragraph. Separate paragraphs with an empty line.

And example of tag is below:

@article
    @title=My title
    Article content.
    Still first paragraph.
 
    More content. This is a new paragraph.
@end

The tags either defines the structure of the documentation (e.g. groups, article, class and member) or helps to define complex formatting (e.g. table or list).
