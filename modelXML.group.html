tag group in Documentation XML Model

Brief

A group of articles, classes and other groups

Parameters
title

The title of the object
key

The unique key of the article (must be unique among articles, groups and classes)
brief

A brief (one-two sentence) summary of the object
in-group

The key of the group to which the object belongs to. All objects except the index group must belong to some group
sort-articles

A flag indicating whether articles needs to be sorted by the name
transform

A flag indicating whether the content contains BB-codes
sort-groups

A flag indicating whether groups needs to be sorted by the name
sort-classes

A flag indicating whether classes needs to be sorted by the name
import-hhc

A name of the custom HTML HELP content file to be added to the group content
import-hhk

A name of the custom HTML HELP keywords file to be added to the group content
briefless
order

If the value is set to "custom" the documentation won't do any grouping or sorting of the objects inside the group

Details

The element may contain the following elements: example, header, list, see-also, table
