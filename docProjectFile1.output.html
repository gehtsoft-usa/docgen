tag output in project.xml file

Brief

The tags defines the output template to be used

Declaration
<output template="path" output="file" encoding="encoding" />

Parameters
template

The name of the main file in the template.

If you build your help file with a standard template and using nuget package (e.g. via MSBuild) you can refer to a standard templates using %docgen%/template/ as the base path.
output

The name of the output file (for templates that creates only one file).

For templates that creates multiple file use this parameter to specify the output folder. However, because the parameter requires a file, add null-file as a file name. The file with such name will not be created, however, its location will be used as base path to create all other files by the template.
encoding

The name of the encoding for output file(s) (e.g. 'ascii', 'utf-8', or 'windows-1252').

Details

The tag should be used one or more time inside of help-project tag.

The section may contain one or more define tags. for template-specific definitions.

Refer the template documentation of the list of the templates available and for the parameters specific for the template.
