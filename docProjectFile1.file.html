tag file in project.xml file

Brief

The tag defines an input file

Declaration
<file name="relative path" encoding="encoding name" />

Parameters
name

The relative path to the file from the folder that contains project.xml file.
encoding

The name of the file encoding (e.g. 'ascii', 'utf-8', or 'windows-1252').

Details

The tag may be used inside source tag.
