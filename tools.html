Tools

Brief

The tools required to author the documentation

Details

To generate the documentation using Gehtsoft Documentation Generator you need to use MSBuild or dotnet build command. You need to have either Microsoft Visual Studio 15 or .NET Core 3.1 SDK (or above) installed. The tool supports both Windows and Linux build and is compatible with Ubuntu-based GIT actions.

Please read Project File section for details on how MSBuild project file needs to be organized.

You can use any text editor as an authoring tool, however we highly recommend to use Microsoft Visual Studio Code with the latest version of DocGen support extension Download the latest version of the extension and install it using the following command

code --install-extension docgen-version.vsix
