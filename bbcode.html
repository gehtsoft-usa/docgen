tags BBCode

Brief

The section describes BBCode that is used to format the source code

Details

The BBCode is well-know formatting specification actively used in phpbb forums and their descendants.

BBCode is supported only by output templates that has the option to format the text. In order to have bbcode processed make sure that default-transform option is enabled in the output template.

BBCode tags should be put in square brackets [].

The opening bbcode tag has format [tagName]

The closing bbcode tag has format [/tagName]

Typically, bbcode with a few exceptions are applied to the text between opening and closing bbcodes, e.g. text [b]bold[/b] text will be displayed as 'text bold text'. Exceptions are tags [nil], [br], [img].

There is no special character to escape an opening square bracket because if it is not recognized as a bbcode, the compiler simply adds it to the text. However, if there is the text that is a correct bbcode, but you want to display it as is, for example myArray[i] + 1 in C++ example will be displayed as 'myArray + 1. To make example look correctly, add [nil] tag after opening square bracket 'breaking' the correct pattern: myArray[[nil]i] + 1,

If bbcode has a value, the value is set after = character after the bbcode name, for example: [color=red]red[[/color].

BBCodes may be used inside other bbcodes, for example: [b]myt[i]e[sub]xt[/sub] is [/i] heavi[/b]ly [u]for[color=gray]mat[/color]ted[/u]. ('mytext is heavily formatted').

Tags

b

Make text bold

blue

Make text blue

br

Inserts a page break.

c

Make text code (monospace)

clink

A link to another topic displayed as a code

color=

Sets the color of the text

eurl

A link to specified URL to be opened in a new window

gray

Make text dark gray

green

Make text green

i

Make text italic

img=

Inserts an image

link=

A link to another topic

nil

Tag that displays nothing.

red

Make text red

s

Make text strikedthrough

size=

Increase or decrease the size of the text

sub

Make text subscript

sup

Make text superscript

u

Underline the text

url=

A link to specified URL to be opened in the same window
