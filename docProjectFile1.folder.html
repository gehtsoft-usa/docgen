tag folder in project.xml file

Brief

The tag defines a source folder.

Declaration
<folder name="relative path" encoding="encoding name" />

Parameters
name

The relative path to the folder from the folder that contains project.xml file.
encoding

The name of the file encoding (e.g. 'ascii', 'utf-8', or 'windows-1252').

Details

All files with extension .ds in the folder specified will be included. There is no warranty about the particular order in which the files will be processed. If you need to handle your files in particular order - use file tag to include each file individually.

The tag may be used inside source tag.
