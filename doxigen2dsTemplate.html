Doxygen2Ds template

Brief

The section describes the template that converts a doxygen XML output to document source

Details

To prepare the source data for the template use the doxygen of version 1.8 or above. Make sure that XML output is enabled (GENERATE_XML = YES in doxygen configuration file).

Please not that this assembly does NOT use DocGen XML document as a source. It opens and processes the document specified in the template parameters. However, because it is still required to have any DocGen XML document, you have to create a source file with an empty index group, e.g. and specify it as a source for your docgen project.

@group
    @title=Index
    @brief=
    @key=main
    @ingroup=
@end

The template is located at %docgen%/template/doxygen2ds/main.xsl

This template creates multiple output files, so use file parameter of the output element of the project file to specify the destination folder:

Example:

<dg:output template="%docgen%/template/doxygen2ds/main.xsl" file="src/raw/null-file" encoding="utf-8">

The template has following parameters:

Parameter

Description

xml-path

The folder where Doxygen XML output is located.

ds-path

The folder to write output docgen source files.

codepage

The codepage for the output files (use 65001 for UTF-8)

group

The group name into which all namespaces must be included.

language

The programming language for declarations

divisor

The divisor to be used in class and namespace names instead of default doxygen's ::. For example, you may want to set it . for Java.

exclude-namespace

The regexp for namespace doxygen identifiers to be excluded from the documentation. For example you may want to exclude java:.+ for Java or ^std$ for C++.

The template is fully refactored in docgen 0.1.17. Check your projects.

The template picks up comment docs as well for brief and detailed description of the classes and methods and for parameter description.

There is limited support of Doxygen markdown (see documentation for details) formatting:

  • Bold, strike-through and code

  • code block with syntax highlighting

  • table, but without row and col span

  • one-level bullet lists

  • links (both to other classes and to URLs) and images
