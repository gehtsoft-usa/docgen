Function files

Brief

Finds all files that matches the specified pattern

Declaration
XPATH
files (folder : string, pattern : string) : node-iterator 

Parameters
folder

The folder to find the files in
pattern

The pattern to search.

If the pattern starts and ends with / character, the pattern is recognized as a regular expression.

Otherwise it is recognized as a filename pattern.

Details

The method returns an iterator of file nodes. Each node has a name attribute.

The function introduced in docgen 0.1.17.
