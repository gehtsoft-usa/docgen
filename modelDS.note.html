tag note in Document Source Format

Brief

A note (highlighted piece of text)

Parameters
type

The type of the note

Check for the template specification for details on the list of the supported types.

For example html template supports note, warning and quote.
if

A name of the definition to be set in the doc project file in order to include the object into the documentation. The value is optional. If no value is set, the object will be always included

Details

The element is supported in docgen 0.1.17+
