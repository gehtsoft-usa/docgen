CS2DS template

Brief

The section describes the template that creates a documentation source using output of Assembly2Xml task and xml docs.

Details

To prepare the source data about content of assembly or assemblies to auto-document, use Asm2Xml task. This task would create a source file for the processing.

Please not that this assembly does NOT use DocGen XML document as a source. It opens and processes the document specified in the template parameters. However, because it is still required to have any DocGen XML document, you have to create a source file with an empty index group, e.g. and specify it as a source for your docgen project.

@group
    @title=Index
    @brief=
    @key=main
    @ingroup=
@end

The template is located at %docgen%/template/cs2ds/main.xsl

This template creates multiple output files, so use file parameter of the output element of the project file to specify the destination folder:

Example:

<dg:output template="%docgen%/template/cs2ds/main.xsl" file="src/raw/null-file" encoding="utf-8">

The template has following parameters:

Parameter

Description

settings

The path to file with XML file with additional settings.

source

The name of the source file generated by Asm2Xml task.

default-group

The template will create a group for each namespace processed.

All these groups will belong to the group specified in this key. Usually the value of this parameter is index, however more complex documentation may require to attach auto-generated content to a specific node in the content tree.
