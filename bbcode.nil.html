tag nil in BBCode

Brief

Tag that displays nothing.

Details

The tag is useful when you need to "break" default behavior of the parser, e.g. when you need to insert a bbcode as a part of the text.

Example: [b]text[/b] will be displayed as text

Example: [[nil]b]text[[nil]/b] will be displayed as [b]text[/b]

Note: this tag has NO closing tag.
