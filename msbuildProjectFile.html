MSBuild Project File

Brief

The section describes MSBuild file defining the project compilation routing

Details

The build file is a standard MSBuild project file. This file may be compiled using either msbuild.exe or dotnet build command.

The docgen relies on two nuget packages available from Gehtsoft public nuget stream https://www.myget.org/F/gehtsoft-public/api/v3/index.json:

  • Gehtsoft.Build.DocGen

  • Gehtsoft.Build.ContentDelivery

You organizes the build process using custom tasks defined in these packages. Refer to project tags for details about the tasks.

You can also expand an example of a project files below that uses all custom tasks:

<?xml version="1.0" encoding="utf-8"?>
<Project Sdk="Microsoft.NET.Sdk">
 <PropertyGroup>
  <TargetFramework>netstandard2.0</TargetFramework>
 </PropertyGroup>
 <!-- Get required packages -->
 <ItemGroup>
  <!-- If you update the package version here,
       don't forget to update it as well below,
       In ContentFromPackage task parameters -->
  <PackageReference Include="Gehtsoft.Build.DocGen" Version="0.1.12" IncludeAssets="build" />
  <PackageReference Include="Gehtsoft.Build.ContentDelivery" Version="0.1.10" IncludeAssets="build" />
 </ItemGroup>
 <!-- Define folder location -->
 <PropertyGroup>
  <DocTargetDir>$(MSBuildProjectDirectory)/dst</DocTargetDir>
 </PropertyGroup>
 <!-- Define file groups and constants -->
 <ItemGroup>
  <!-- Images and raw HTML files to include into doc -->
  <CustomFile Include="$(MSBuildProjectDirectory)/img/**/*.png;$(MSBuildProjectDirectory)/html/**/*.*" />
  <!-- All files in target directory -->
  <CurrentDocTargetDir Include="$(DocTargetDir)" />
 </ItemGroup>
 <!-- Target that removes results of compilation -->
 <Target Name="CleanDoc">
  <RemoveDir Directories="@(CurrentDocTargetDir)" />
 </Target>
 <!-- Target that creates the project -->
 <Target Name="MakeDoc">
  <!-- Remove previous output -->
  <RemoveDir Directories="@(CurrentDocTargetDir)" />
  <MakeDir Directories="$(DocTargetDir)" />
  <!-- Compile documentation project -->
  <DocGen Project="project.xml" />
  <!-- Copy raw content to the output folder -->
  <Copy SourceFiles="@(CustomFile)" DestinationFolder="$(DocTargetDir)" />
  <!-- Copy content (e.g. web menu, icons, scripts) for HTML template output -->
  <ContentFromPackage Package="Gehtsoft.Build.DocGen" Source="Content/template/html/res" Version="0.1.12" Destination="$(DocTargetDir)/res" />
  <ContentFromPackage Package="Gehtsoft.Build.DocGen" Source="Content/template/html/highlighter" Version="0.1.12" Destination="$(DocTargetDir)/highlighter" />
  <ContentFromPackage Package="Gehtsoft.Build.DocGen" Source="Content/template/html/menu" Version="0.1.12" Destination="$(DocTargetDir)/menu" />
  <ContentFromPackage Package="Gehtsoft.Build.DocGen" Source="Content/template/html/pageImages" Version="0.1.12" Destination="$(DocTargetDir)/pageImages" />
 </Target>
</Project>
projectCommand
dotnet build project.proj /t:CleanDoc,MakeDoc
