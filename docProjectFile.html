Documentation project

Brief

The section describes XML file defining the documentation project

Details

The documentation project file defines:

  • The common properties of the project

  • The location of the source files and compiler rules

  • The output templates to be used and their parameters

Follow the project file scheme to define the project content.

The root element of the project file is help-project.
