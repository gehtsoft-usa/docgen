Function call

Brief

Calls another XSLT file and return the transformation result as a string

Declaration
XPATH
call (xslt : string, target : node) : string 
XPATH
call (xslt : string, target : node, encoding : string) : string 

Parameters
xslt

The path to the template to be called.

If the template address is relative, the doc compiler first check the location relatively to the current work directory.

If there is no template with such name in the current work directory, the doc compiler searches the template relatively to the first XSLT file being called.

The feature allows you to "replace" some XSLT files in the default without need to copy a template completely.
target

The node to the node which will be used as the root for the template executed.
encoding

The name of the encoding. If encoding is not enforced, UTF-8 will be used.

Details

This function returns the transformation result as a text.

If you want to save it as a file, use another call extension function.
