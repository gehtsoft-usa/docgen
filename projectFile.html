Documentation Project Files

Brief

The section described the documentation project files

Details

There are two kind of the project files you need to create in order to successfully compile a documentation project:

1) A msbuild project file that calls all required actions

2) A docgen project file that sets the source of the documentation and defines the desired documentation output.
