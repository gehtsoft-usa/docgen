Function parsebbcode

Brief

The method parses text that contains bbcode

Declaration
XPATH
parsebbcode (value : string) : node 

Parameters
value

The text to be parsed

Details

The structure of XML document follows the structure of bbcode with the following additions:

  • The root tag of the returned document will be <r>

  • All pieces of the text will be wrapped into <t> tag

  • Wherever the bbcode attribute has a value, it will be saved into attr attribute.

Example

BBCode: My [b]bold and [color=green]green[/color][/b] text

Will be parsed into:

XML

<r>
 <t>My </t>
 <b>
   <t>bold and </t>
   <color attr="green">
     <t>italic</t>
   </color>
 </b>
 <t>text</t>
</r>
