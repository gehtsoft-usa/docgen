tag strip-namespace in Settings File Schema

Brief

The list of namespaces those names should be displayed as a short name rather than full name

Parameters
name

The name of namespace.

Details

The types to belong to the assembly specified will be shown in the documentation using their short names rather than full names.

The following areas will be affected:

  • The list of class parents

  • The types of the parameters in declarations

  • The return types in the declarations

E.g. by default an auto-generated declaration may look like these

System.Task<System.Collections.Generic.List<T>> Sample<T>(System.Collections.Generic.IEnumerable<T> parameter);

If you add the following lines to the project file

<settings>
 ...
 <strip-namespace name="System" />
 <strip-namespace name="System.Collections.Generic" />
 ...
</settings>

The declaration will look like this

Task<List<T>> Sample<T>(IEnumerable<T> parameter);
