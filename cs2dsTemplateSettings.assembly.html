tag assembly in Settings File Schema

Brief

The assembly to be processed

Parameters
name

The name of the assembly without .dll extension.
xmldoc

The path to the XML Doc file generated by C# compiler from source code comments. The path specified must be relative to a location of the assembly file from which the source XML document is generated.

This value is optional. If no XML doc location is set, the documentation will be generated for the structure, without any descriptions included.

Details

The element defines the assembly to be processed.
