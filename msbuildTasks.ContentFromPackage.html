tag ContentFromPackage in Tasks

Brief

The custom task copies content from a package folder to the specified folder

Declaration
<ContentFromPackage Package="" Version="" Source="" Destination="" />

Parameters
Package

The name of the package, e.g. gehtsoft.build.docgen

In order to make it operable in Linux make sure that you use all lowercase in the package name!
Version

The version of the package, e.g. 0.1.12

When you are copying from gehtsoft.build.docgen don't forget update the version in this task every time when you update the version in project reference.
Source

The folder inside the package to copy data from.

In order to make operable in Linux, use / as path separator.
Destination

The folder to copy data to.

In order to make operable in Linux, use / as path separator.
